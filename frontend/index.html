OmniRAG System Architecture & Workflow

A comprehensive end-to-end breakdown of how multi-format documents are ingested, vectorized, retrieved, and synthesized into grounded answers.

Phase 01
📥

Universal Ingestion

Accepts any file type through a unified ingestion interface.

  • PDF: PyMuPDF (fitz) extracts text, font metadata, and page numbers
  • Word (.docx): python-docx parses paragraphs & tables
  • Slides (.pptx): python-pptx extracts slide shapes & notes
  • Excel/CSV: pandas/openpyxl formats structured tabular data
  • Code/Text: Universal multi-encoding auto-detect (UTF-8, Latin-1)
Phase 02
✂️

Semantic Chunking

Transforms raw multi-page text into dense context chunks.

  • Recursive Boundary Split: Paragraphs → Sentences → Words
  • Chunk Window: ~800 characters with 150-char overlap
  • Context Preservation: Overlap prevents fragmented sentences
  • Metadata Attachment: doc_id, filename, page_num, section_title
Phase 03
⚡

Vector Embedding & Storage

Embeds chunks into high-dimensional semantic vector space.

  • Embedding Model: all-MiniLM-L6-v2 (Chroma ONNX Neural Engine, 384-dim) or gemini-embedding-2
  • Vector Database: ChromaDB persistent vector collection
  • Indexing: Fast HNSW (Hierarchical Navigable Small World) index
  • Zero-Cloud Local Mode: Runs entirely local offline without API dependency
Phase 04
🔍

Semantic Retrieval

Retrieves the most semantically relevant chunks for any question.

  • Question Vectorization: User prompt is projected into embedding space
  • Cosine Similarity: K-Nearest Neighbors (KNN) calculates distance
  • Top-K Selection: Filters top 4 most pertinent source chunks
  • Filtering: Supports filtering by specific uploaded document
Phase 05
🧠

Grounded LLM Synthesis

Produces an accurate, cited answer strictly backed by source evidence.

  • LLM Engine: gemini-2.5-flash (Google GenAI)
  • Grounded System Prompt: Strict anti-hallucination constraint
  • Inline Citations: Automatically marks [Source 1], [Source 2]
  • Interactive Inspector: Click any citation to inspect the raw passage
